# ujjwal-frontend

Vite + React 19 + TypeScript, GSAP (ScrollTrigger) and Lenis, Three.js for the 3D meter map.

```bash
npm install
npm run dev          # local dev server
npm run build        # production build in dist/ (deploy to Vercel, Netlify or GitHub Pages)
npm run build:single # one self-contained index.html in dist-single/
```
